# Luftborn Product Management

A product management application built with ASP.NET Core Web API and JavaScript. The application demonstrates RESTful API development, product data management, and frontend-to-backend integration.

## Features

- Retrieve and display products.
- Communicate with the backend through HTTP requests and JSON.
- Separate frontend presentation from backend application logic.
- Provide a foundation for extending product management functionality.

## Tech Stack

**Backend**
- C#
- ASP.NET Core Web API
- Entity Framework Core / database integration

**Frontend**
- HTML5
- CSS3
- JavaScript
- Fetch API

**Development Tools**
- Visual Studio
- Git
- .NET SDK

## Architecture

The application separates the frontend from the backend API.

- **Frontend:** Renders the user interface and sends HTTP requests.
- **Backend:** Exposes API endpoints and handles application requests.
- **Data access:** Responsible for persistence and database operations, where configured.

The frontend communicates with the backend through REST-style HTTP endpoints and exchanges data in JSON format.
